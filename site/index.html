Pit Wall

Count every race in the results table, as a naive query would, and Chase Elliott and Joey Logano tie for the most Cup wins of 2022. The right answer is Elliott alone: one of Logano's "wins" was the Clash, an exhibition. Pit Wall is an MCP server that lets AI assistants answer NASCAR questions from SQL with the definitions built into every tool, and every answer shows the query that produced it.

How it works

From race results to trusted answers

DataEvery Cup Series race 2022–2026 from NASCAR's public results feeds: finishes, starts, laps led, status, team, make, plus race-level lead changes and cautions.
SQL + definitionsDuckDB tables and views. A win, a top 10, a DNF and an average finish are each defined once, in SQL, for points races only.
MCP serverEight tools an AI assistant can call, each with a description that carries the definitions and asks instead of guessing when a name is ambiguous.
ValidationEvery tool answer, called through the real MCP protocol, is checked against a trusted query written directly on the raw tables.

Every answer shows its work

Each tool returns the answer, the definitions it applied (basis) and the exact query that produced it (sql). A person checking an AI assistant's claim doesn't have to trust the assistant: paste one query into DuckDB and see the same numbers. The validation suite reruns every cited query and confirms it reproduces the answer.

Validation

    
Every answer, checked against trusted SQL

    
Each question below is asked through the MCP protocol exactly as an assistant would ask it. The answer is compared with a trusted query written separately against the raw tables, not the views the tools share, so a mistake in the shared business logic shows up as a failure. The suite runs in one command and must pass before anything ships.

    

    

  






  

    
Where AI answers go wrong

    
Definitions are where the errors hide

    
A language model writing its own SQL will usually produce something that runs. The danger is that it runs on the wrong definition. These are the traps in this data, measured. Each one is handled in the tool layer and covered by a test.

    

  






  

    
Forecast

    
Who finishes in the top 10?

    

      

        
The top10_probability tool is a logistic regression on facts known before the green flag: starting spot, the driver's last 10 races, his record on that type of track, his team's recent form and the field size. It was trained on 2022–2025 and tested on all 36 races of 2026, which it never saw.

        

        

      

      

        
Calibration on 2026

        
When the model says 30%, about 30% should finish top 10.

Limits

    

      
The validation suite tests the tools, through the protocol, against trusted SQL. It does not grade a language model's free-form wording; the same harness can grade any assistant's answers by swapping in its tool calls. Track types are a documented judgment call. The forecast's edge over the starting grid is real but modest (it is a 36-race test), and it knows nothing about pit strategy, wrecks or weather. Results come from NASCAR's public feeds; 18 points-race finishes have no status recorded and are not counted as DNFs.
